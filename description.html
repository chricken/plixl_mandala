Plixl Mandala

An easy to use but powerful Mandala Creator

AI Status

This App has been Vibe Coded for the best part plus a few manual touches.

Layers

Different layers can be created; each layer accepts various options:

  • Type of element (circle, rectangle, triangle, text, path, nested mandala)
    • For circle: radius, start angle, end angle
    • For rectangle: width, height, angle
    • For triangle: width, height, angle
    • For text: text, font, font size
    • For path: see paths below
    • For nested mandala: mandala with all possibilities
  • Stroke color, fill color
  • Line width
  • Position (x, y)
  • Rotation
  • Opacity

For each layer it can be determined how it shall be copied:

  • How many copies there shall be
  • How large the total angle is
  • An offset that influences the position of the copies
  • A scaling
  • The opacity can also be determined
  • The fixed point can be determined

Layers can be nested, so that one layer contains several layers. If a layer contains another mandala, that other mandala is subjected to the rules of the layer.

Paths

When a path is selected as an element, it shall be displayed on the canvas.

The individual anchor points of the path are displayed and can be moved with the mouse. Each anchor point also has two handles that determine the slope of the curve at that point. These handles can also be moved.

Handles over which the mouse hovers are highlighted (perhaps with a shadow?).

Layer Display

There is an overview of the layers, similar to Illustrator and the like.

  • Layers can be moved into and after one another (drag and drop).
  • They can be hidden (checkbox).
  • They can be deleted (trash can).
  • They are given a name (text field).
  • Nested elements are displayed indented

The element displaying the layers can be freely moved, minimized and docked.

Export

Mandalas can be exported in various formats:

  • SVG
  • PNG
  • JPG

The SVG shall be based on the description and shall afterwards be editable in a vector program.

The size of the export must be configurable.
